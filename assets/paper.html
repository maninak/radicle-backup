How to use this sheet

  1. Install Radicle, then rad-backup, on the machine you are recovering to.
  2. If this sheet shows words: run rad-backup restore --words and type them in. It will rebuild the key and ask you for a new passphrase.
  3. If this sheet shows a key file: scan or retype it into $RAD_HOME/keys/radicle, then run chmod 600 on it, and derive the public half with ssh-keygen -y -f $RAD_HOME/keys/radicle > $RAD_HOME/keys/radicle.pub.
  4. Check that you got the right one: ssh-keygen -l -f $RAD_HOME/keys/radicle.pub should print the fingerprint above.
  5. Start the node with rad node start. Your public repositories come back from the network with rad clone. Private ones do not: only your own archives have those.

Never run two nodes with this key at the same time. They will sign conflicting histories and other people's nodes will see your identity fork.
