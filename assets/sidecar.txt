This plain-text note sits next to the archive so that whoever finds it knows what it is and
how to open it, without needing rad-backup to tell them.

Open it with rad-backup:

    rad-backup verify  {{FILE}}     # prove it is complete and readable
    rad-backup list    {{FILE}}     # see what is inside
    rad-backup restore {{FILE}}     # put it back

    {{MANUAL}}

Then read RESTORE.md inside, which restores the whole home with git and cp alone.
